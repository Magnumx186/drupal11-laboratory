# Ejemplo de Documentación

## Descripción
Este es un ejemplo básico de un archivo HTML con elementos interactivos.

## Estructura del Proyecto
- `index.html`: Contiene el código HTML, CSS y JavaScript.

## Funcionalidad
1. Muestra un mensaje inicial: "Este es un ejemplo simple."
2. Al hacer clic en el botón, el mensaje cambia a: "El texto ha sido modificado!"

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript puro

## Cómo ejecutar
1. Guardar el contenido de `index.html` en un archivo con extensión `.html`
2. Abrir el archivo con cualquier navegador web
3. Hacer clic en el botón para ver la interacción
